# CM-26dG Colour Explorer

Interactive colour-science teaching platform.

## Features

- Reflectance spectra plotting
- SCI / SCE comparisons
- CIELAB calculation
- CIE xy chromaticity
- sRGB colour preview
- ΔE2000 comparisons
- Radiance material export
- DIALux material export
- PDF report generation

## Run locally

pip install -r requirements.txt

streamlit run app.py
